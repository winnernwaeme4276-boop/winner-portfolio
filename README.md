# Winner Nwaeme Portfolio

A responsive freelance frontend developer portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Included

- Services, selected work, certifications, About, skills, and contact sections
- Responsive navigation and reveal animations
- Links to the Veyra Fashion Catalogue demo and verified contact/GitHub destinations

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static web server.

## Project structure

- `index.html` — page markup and content
- `css/style.css` — visual styles and responsive layout
- `js/app.js` — mobile navigation and reveal animations
- `assets/` — certificate and portfolio assets
